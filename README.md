# MQTT MCP

Publishes and subscribes over MQTT. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mqtt-mcp

Installs from the Camillia hub as `mqtt-mcp-caf21d`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
